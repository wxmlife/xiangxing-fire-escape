# 巷行 · 城中村火灾逃生线路模拟

一个面向手机端的沙盘逃生线路演示网站。当前示例根据实拍沙盘还原建筑、杂物、火源、白色泡沫围挡、绿色门起点，以及图片上方两处安全出口 E1 / E2。

在线访问：<https://wxmlife.github.io/xiangxing-fire-escape/>

## 功能

- 自动识别任意数量的黄绿色门牌候选，不再把起点强制截成 7 个；可切换总线路和每个起点的分线视角。
- 上传新的正俯拍图片后，同时生成绿门、障碍与有效沙盘规划区候选；规划区可手动重画，区外始终禁行。
- 绿门使用颜色、面积和矩形度联合判定；被门牌规则拒绝的高饱和绿色玩具会继续作为障碍候选。
- 白色泡沫、建筑、纸箱、车辆及封闭区域按硬障碍处理；未完成“障碍已复核”时不会生成路线。
- “训练集”可在本机上传五类紧裁切样本：建筑、障碍物、火源、逃生者起点绿门和白色泡沫（障碍）。建筑/障碍/泡沫增加不可通行候选，火源增加风险点候选，绿门增加起点候选；所有匹配结果始终标为待复核，可人工修正，并可导出 JSON 数据集。
- “场景记录”可命名、保存、切换、重命名和删除历史规划；刷新会恢复最后一次打开的场景。当前为无登录的本机浏览器存储。
- “模拟撤离排行”支持任意人数，按路线长度估算演示用时，并明确列出已撤离与受阻人员。
- 当前演示把有效人员宽度设为沙盘图宽的 4.6%，运行时会随规划分辨率换算；108 列网格下对应 5 格，因此 6 号楼左侧的三格窄缝会被封闭。
- 已确认门口如果被粗粒度自动障碍框覆盖，只会开出一条受限的最小连接通道；白色泡沫与火源硬禁区绝不允许这样开口。
- 自适应桌面和手机屏幕。

## 建模与规划方法

1. 将俯拍照片归一化到二维沙盘坐标，先自动估算有效规划区，再支持人工拖框校正。
2. 建立“可通行 / 硬障碍 / 待确认”占据栅格。
3. 按人员宽度、识别误差和安全余量扩张障碍；通道阈值为 `2 × 膨胀半径 + 1`。
4. 用 A* 搜索路线，把距离、火源风险和通道拥堵计入代价。
5. 按顺序规划任意数量的起点路线，并累计通道占用成本以鼓励分流。

更换沙盘时只需替换并重新校准场景数据，规划引擎不变。

## 本地运行与测试

```bash
python3 -m http.server 4173 --directory dist
node --test tests/planner.test.mjs
```

## 一键更新与发布

修改完成后，在项目目录运行：

```bash
./publish.sh "说明这次修改了什么"
```

脚本会依次更新静态资源版本、运行测试、提交网站文件、推送到 GitHub，并等待 GitHub Pages 部署成功。只想检查而不提交时运行：

```bash
./publish.sh --dry-run
```

## 重要说明

本项目用于沙盘几何路径模拟和教学演示，不可直接作为真实火场疏散指令。真实部署还必须接入经过标定的相机、烟气与温度数据、出口实时可用性、建筑消防规范和现场人工确认。
